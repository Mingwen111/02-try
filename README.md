# 02 尝试

基于 Vue 3 + Vite 的小型网站开发环境。

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 当前设计规范

- 字体使用 `Noto Sans SC`。
- 固定间距以 `4px` 为最小单位，所有间距使用 4 的倍数。
- `1920 × 1080` 是 section 的设计基准，不强制所有 section 使用固定高度。
- section 默认内容驱动高度，允许根据内容变短或变高。
- 色彩使用比例：灰色系约 80%，主色约 15%，辅助色和系统色约 5%。
- 文本颜色最多使用 3 个层级，默认使用主文本和次文本两个层级。
